# FastSalesforce — Política de privacidad

Página pública con la política de privacidad de la extensión **FastSalesforce** para Chrome.

- **URL:** https://sergioxp.github.io/fastSalesforce-privacy/
- **Idiomas:** español e inglés en la misma página.
- **Contenido:** un único `index.html` autocontenido (sin CDN, sin fuentes externas, sin JavaScript).
- **Motivo:** la Chrome Web Store exige una URL de política de privacidad accesible sin iniciar sesión.

Este repositorio contiene **solo** el texto de la política. El código de la extensión vive en un
repositorio privado aparte.

## Editar la política

1. Modifica `index.html` (secciones `#es` y `#en`).
2. Actualiza la fecha del encabezado («Última actualización»).
3. Commit y push a `main`: GitHub Pages publica solo en ~1 minuto.
