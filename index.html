Español

Resumen: FastSalesforce no tiene servidores propios. No hay analítica, ni telemetría, ni publicidad, ni cuentas de usuario. Todo lo que guarda se queda en el almacenamiento local de tu navegador y la extensión solo lee de tu org de Salesforce.

Qué es la extensión

FastSalesforce es una extensión de navegador que añade atajos a las páginas de Setup de Salesforce y una vista para inspeccionar cómo se comparten los registros (quién tiene acceso, por qué y con qué permisos de campo).

Qué se guarda en tu navegador

Únicamente, y siempre en chrome.storage.local de tu equipo:

  • La sesión de API de la org que ya tienes abierta (la cookie sid), guardada por org y con caducidad corta, para poder llamar a la API de esa org en tu nombre.
  • Una caché temporal de los metadatos (objetos y campos) de los que consultas.
  • La lista de los últimos registros abiertos en el inspector.
  • Tu preferencia de tema: automático, claro u oscuro.
  • Qué atajos de Setup has activado en la barra.

Nada de esto se sincroniza con ningún servidor. Se puede borrar desinstalando la extensión; además, la sesión guardada se elimina automáticamente cuando la cookie sid desaparece (es decir, al cerrar sesión en la org).

A qué se accede

Solo a las páginas de Salesforce y a la API de la org en la que has iniciado sesión, para leer la configuración de compartición, los permisos y los metadatos que ya puedes ver en Salesforce. La extensión no modifica registros ni metadatos.

Qué no se hace

  • No se recopilan datos personales.
  • No se venden ni se comparten datos con terceros.
  • No se usan para publicidad, perfilado ni para evaluar solvencia.
  • No se ejecuta código remoto: todo el código va dentro del paquete de la extensión.

English

Summary: FastSalesforce has no servers of its own. There is no analytics, telemetry, advertising or user account. Everything it stores stays in your browser's local storage, and the extension is read-only against your Salesforce org.

What the extension is

FastSalesforce is a browser extension that adds shortcuts to Salesforce Setup pages and a view that explains how records are shared (who has access, why, and with which field permissions).

What is stored in your browser

Only this, and always in chrome.storage.local on your machine:

  • The API session of the org you are already signed into (the sid cookie), stored per org with a short lifetime, so requests to that org's API can be made on your behalf.
  • A temporary cache of the metadata (objects and fields) you inspect.
  • The list of the last records opened in the inspector.
  • Your theme preference: auto, light or dark.
  • Which Setup shortcuts you enabled in the bar.

None of it is synced to any server. It can be removed by uninstalling the extension, and the stored session is deleted automatically as soon as the sid cookie disappears (that is, when you sign out of the org).

What is accessed

Only Salesforce pages and the API of the org you are signed into, to read the sharing configuration, permissions and metadata you can already see in Salesforce. The extension does not modify records or metadata.

What is not done

  • No personal data is collected.
  • No data is sold or shared with third parties.
  • No data is used for advertising, profiling or creditworthiness.
  • No remote code is executed: all code ships inside the extension package.

Permissions and what they are for

PermissionPurpose
storageKeep the per-org session, metadata cache, recent records and theme locally.
cookiesRead only the sid cookie of the open org, to authenticate calls to its API. The value never leaves the browser.
Salesforce domainsInject the shortcut bar in Lightning and query the org's own API.

No tabs, scripting or access to any other website is requested.
